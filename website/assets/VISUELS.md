# Visuels du site

Les fichiers ci-dessous sont des illustrations generees avec l'outil
image_gen integre, sans appel a la cle OpenAI du projet. Aucun visuel n'est
une photo personnelle ou une preuve d'analyse d'un objet reel. Les deux
captures workspace.png et premiere-ouverture.png proviennent de l'application
en mode demonstration. Les icones sont generees depuis lucide-react ; leur
licence ISC est conservee dans icons/LICENSE.txt.
Les captures ont ete actualisees pour le nom Lotigo. L'icone de marque utilise
Layers (lots), egalement present dans l'application et son installateur.

La page utilise objets-hero-v3.webp, lampe-demo-v2.webp, appareil-demo-v2.webp
et chaise-demo-v2.webp. Ces quatre versions sont des encodages WebP des PNG
originaux, sans changement de dimensions ni de cadrage. Le visuel hero-v2
est conserve comme source de la revision v3, mais n'est pas affiche sur le site.

## objets-hero-v3.png (version utilisee)

Edit cible : objets-hero-v2.png. Prompt final :

Edit the referenced hero photo, keeping the three illustrated objects (green articulated lamp, vintage camera, red chair) realistic and completely visible. Produce an EXTRA WIDE LANDSCAPE composition approximately 2.2:1, ideally 2048 by 928 pixels. Extend the image substantially to the LEFT with seamless empty photographic background so the left 55 percent is completely free of objects. Reduce the height of the grouped objects to occupy only the central 70 percent of the canvas height, leaving substantial top and bottom margins, for a responsive full-width webpage hero that will not crop the lamp or chair feet. The entire far-left area must be perfectly uniform pale cool grey, matching hex #e3e5e6 as closely as possible, with no floor seam, vertical panel, vignette or texture. Use the same background colour across the studio, with realistic soft shadows only beneath the objects on the right. Keep the same forest green, coral red, white plinths and charcoal palette. No text, logo, watermark or webpage graphics. This is an illustrative product photograph.
